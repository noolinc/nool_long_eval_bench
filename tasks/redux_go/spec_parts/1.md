# Sub-task 1 of 2: Core store

You are one of two engineers working in parallel branches of this repository
(package `redux`, module already in `go.mod`). Your teammate is implementing
CombineReducers and the middleware system on another branch, coding against
the contract below. Do not implement their part.

Implement in `redux.go`:

```go
// Action carries a type tag and an optional payload.
type Action struct {
    Type    string
    Payload any
}

// Dispatcher consumes an action and returns it (possibly modified).
type Dispatcher func(action Action) Action

// CreateStore builds a store from a reducer func(S, Action) S and an
// initial state S. The returned *Store[S] must provide:
//   GetState() S
//   Dispatch(action Action) Action
//   Subscribe(listener func()) (unsubscribe func())
// Dispatch applies the reducer, then notifies subscribed listeners.
// Unsubscribe stops future notifications for that listener.
func CreateStore[S any](reducer func(S, Action) S, initial S) *Store[S]
```

Design note your teammate depends on: `Store[S]` must keep its dispatch
behavior in a way an enhancer can later wrap (their `CreateStoreWithEnhancer`
will need to replace/wrap the store's dispatch chain). Expose whatever
minimal surface you judge right for that, and document it in a short comment.

Do not write tests. When your part builds (`go build ./...`), land your work
with the version-control workflow available in this repository, then stop.
